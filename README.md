# Pult

Handy-App für den Kunstunterricht: laufende Phase mit Restzeit, Verzug neu rechnen, Spickzettel, Notizen.
- `app.html`: die App (Vorlage), `index.html` und `artifact.html` werden daraus gebaut.
- `daten/heute.json`, `daten/morgen.json`: Tagesdaten, täglich vom Morgenlauf (`morgenlauf/anleitung.md`).
- `werkzeuge/bauen.py`, `werkzeuge/test.py`: bauen und testen.
- Keine Schülernamen, keine Noten. Notizen bleiben im Browser des Handys.

Erstellt mit Unterstützung von Claude (KI-Assistent von Anthropic).
