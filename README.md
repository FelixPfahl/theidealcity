# Folien

Präsentationen bauen, prüfen und vorführen, im Browser am PC (Chrome).
- Präsentationen sind Dateien `.atelier.json` im Klassenordner in Drive. Speichern mit Strg+S.
- Folientypen: Titel, Ablauf, Frage, Werk ganzseitig, Werk mit Text, Text, Zitat, Bildvergleich, Arbeitsauftrag, Bewertung (Oberstufe), Quellen mit KI-Hinweis.
- Uhrzeiten, Sozialform und Dauer kommen aus den Phasen der Stunde (spiegeln den Verlaufsplan).
- Prüfung nach Josefs Regeln (Sozialformen, Lehrerbegriffe, Pflichtfolien, Bewertung, Anrede, Werkfolien).
- Vorführen mit Ecken-Uhr, Timer (T), Schwarzbild (B), Kopplung mit Pult und Fernbedienung vom Handy; Canva-PDFs als Rückfall.
- Bauen: `python3 -I werkzeuge/bauen.py`, Testen: `python3 -I werkzeuge/test.py <bilderordner>`.
- Keine Schülernamen, Noten oder privaten Kennungen in diesem Zweig.
