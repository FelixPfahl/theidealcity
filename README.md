# Atelier Folien (Windows)

Programm für das Notebook: öffnet die neueste Folien-Datei (`Atelier_Folien_*.html`) aus Downloads,
gibt die Dokumentenkamera frei und aktualisiert sich selbst.

Installieren: https://github.com/FelixPfahl/theidealcity/releases/latest/download/Atelier-Folien-Setup.exe

Gebaut von GitHub Actions bei jedem Push auf diesen Zweig. Enthält keine Unterrichtsdaten.

Erstellt mit Unterstützung von Claude (KI-Assistent von Anthropic).
