Je Stunde läuft die Präsentation aus diesem Werkzeug, sonst das Canva-PDF als Rückfall (Zuordnung über den Dateianfang, z. B. 07_ für die 7a).
Vorführen: → Leertaste Bild ↓ weiter, ← Bild ↑ zurück, B Schwarzbild, T großer Timer, N nächste Phase von Hand, F Vollbild, Esc zurück.
Präsentationen sind Dateien (.atelier.json) im Klassenordner in Drive. Speichern mit Strg+S. Dieser Browser merkt sich zusätzlich eine Kopie, damit nichts verloren geht.
